# ITINERARY-CONTROL-SYSTEM
Itinerary Control System is a web-based travel platform with role-based access. Users can register, log in, book tours, manage bookings, and raise issues. Admins can create and manage packages, users, bookings, inquiries, and site content. Guests can browse and submit inquiries. Built with PHP, HTML,CSS, Javascript, MySQL, and Bootstrap.
